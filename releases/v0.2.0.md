# Snip 0.2.0

- Improved contrast for the Settings control and fixed the source picker layout.
- Choose a clip naming pattern with `{date}` and `{time}`, such as `clip_{time}_{date}`. A short ID prevents collisions.
- The menu bar controls use a translucent material background.
- Includes separate video, app audio, and microphone source choices from 0.1.4.

Requires an Apple Silicon Mac with macOS 15 or later. The app is ad hoc signed and not notarized. On first run, if macOS blocks the app, open **System Settings → Privacy & Security → FileVault → Open Anyway**, confirm, and launch Snip again.
