# Snip 0.1.3 preview

Snip now has a dark control window and a compact menu bar panel inspired by the supplied Glim references. The full editor opens on recorded video color controls, with a preview, quick looks, and brightness, contrast, and saturation sliders. Settings keeps the existing video, source, clip, and app options. The menu bar panel provides capture, save, color, and full editor controls.

Color adjustments change saved clips; they do not change the Mac display or backlight. The preview is an approximation. The app location choice places Snip in the menu bar or Dock.

## Download and install

Download **Snip-v0.1.3-preview-macos-arm64.zip** and its SHA-256 checksum file below. Snip requires an Apple Silicon Mac running macOS 15 or later.

1. Unzip and move **Snip.app** to **Applications**.
2. Open Snip. This preview is ad hoc signed and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after the first attempt. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Grant **Screen & System Audio Recording** when asked. If you change this permission in System Settings, quit and reopen Snip.
4. Click the Snip menu bar icon to open compact controls, then choose **Full editor** for the complete settings window. **⌘⇧9** saves a clip; **⌘⌥P** pauses or resumes capture.

Place the checksum file beside the ZIP and run `shasum -a 256 -c Snip-v0.1.3-preview-macos-arm64.zip.sha256` to verify the download.
