# Snip 0.1.0 preview

Native macOS rolling screen capture for saving recent gameplay or desktop activity with a global shortcut.

**Download:** `Snip-v0.1.0-preview-macos-arm64.zip` below. Requires Apple Silicon and macOS 15 or later. SHA-256 checksum is provided alongside the ZIP.

## Install

1. Unzip and move **Snip.app** to **Applications**.
2. Open it. This preview is ad hoc signed and **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after the first launch attempt. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Grant **Screen & System Audio Recording** permission when requested, then restart Snip if macOS asks.
4. Use the menu bar icon to open Settings. Default shortcuts: **⌘⇧9** saves a clip and **⌘⌥P** pauses or resumes. Both are customizable.

## Included

- Compressed rolling buffer with adjustable duration and memory cap.
- 30, 60, or 120 FPS selection, full physical Retina capture, custom size, and bitrate control.
- Separate allow or ignore rules for video apps and app audio.
- Recorded video brightness, contrast, and saturation controls.
- Custom clip name, save folder, shortcuts, sound cue, and menu bar visibility.
- Display refresh cap: a 120 FPS selection on a 60 Hz display requests up to 60 FPS.

## Measurements

On one M4/16 GiB Mac, two 30-second stationary desktop observations at 2940 × 1912 Retina resolution showed median Snip CPU of **21.0% before** and **5.1% after** the display refresh cap, with median resident memory of **151.41 MiB** and **134.36 MiB**. `ps` CPU percentage uses 100% for one logical CPU. These single observations are not a gameplay benchmark or a guaranteed speedup. A saved clip's HEVC dimensions matched the physical display resolution. See the [full report](https://github.com/Duncanyu/clipper/blob/main/benchmarks/2026-10-13-m4.md) and [raw data](https://github.com/Duncanyu/clipper/tree/main/benchmarks/raw).

The [README](https://github.com/Duncanyu/clipper#readme) has usage, build, and measurement instructions.
