# Snip 0.1.2 preview

Save the recent screen as a `.mov` clip with **⌘⇧9**. Snip records full Retina output with hardware HEVC encoding and a compressed rolling buffer.

```text
Screen → hardware HEVC → rolling buffer ─┐
App sound ────────────────────────────────┼→ shortcut → .mov clip
Microphone (optional) ────────────────────┘
```

## Download and install

Download **Snip-v0.1.2-preview-macos-arm64.zip** below. It requires Apple Silicon and macOS 15 or later. A SHA-256 checksum file is included.

1. Unzip and move **Snip.app** to **Applications**.
2. Open Snip. This preview is ad hoc signed and **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after the first attempt. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Grant **Screen & System Audio Recording** when asked. If you change this permission in System Settings, quit and reopen Snip.
4. Open **Settings → Sources** to turn **Record microphone** on. macOS asks for **Microphone** permission only when you enable it. App sound and microphone are independent switches; app sound rules do not filter the microphone.
5. **⌘⇧9** saves a clip; **⌘⌥P** pauses or resumes. Both shortcuts can be changed in Settings.

## What changed

- Added a separate microphone toggle and native microphone permission request. When enabled, Snip mixes microphone and app sound into one AAC track in saved clips. Microphone capture is off by default.
- Replaced image charts in the README and benchmark report with Markdown tables and text bars that stay readable on GitHub and in source view.
- Pausing capture now keeps the idle Snip menu bar icon. ScreenCaptureKit’s normal stop callback no longer appears as a warning state.

## Measured performance and quality

The existing measurements below were collected with **microphone off** on one M4 Mac at **2940 × 1912 Retina**, 16 Mbps target, system audio on, and a 60 Hz display. Each `█` is about 1 percentage point of one logical CPU.

| Observation | Median CPU | Median process RSS |
| --- | --- | ---: |
| Stationary before refresh cap | `█████████████████████` 21.0% | 151 MiB |
| Stationary with refresh cap | `█████` 5.1% | 134 MiB |
| Moving tiles before audio trim change | `█████` 5.3% | 155 MiB |
| Moving tiles after audio trim change | `████` 4.1% | 149 MiB |

| Saved clip check | Before audio trim change | After audio trim change |
| --- | ---: | ---: |
| Encoded size | 2940 × 1912 | 2940 × 1912 |
| Mean decoded frame rate | 57.24 FPS | 57.38 FPS |
| Median frame gap | 16.67 ms | 16.67 ms |
| Whole-file bitrate | 16.50 Mbps | 15.86 Mbps |

These are single observations of a synthetic moving window, not a game benchmark or microphone-on measurement. See the [full method and limits](https://github.com/Duncanyu/clipper/blob/main/benchmarks/2026-10-13-m4.md), [raw samples](https://github.com/Duncanyu/clipper/tree/main/benchmarks/raw), and [measurement script](https://github.com/Duncanyu/clipper/blob/main/scripts/benchmark.py).
