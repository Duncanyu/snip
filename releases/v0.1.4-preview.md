# Snip 0.1.4 preview

The main window and menu bar panel now focus on recording: capture status, saving the recent clip, clip length, quality, sources, and save location. Optional recorded video color adjustments live in a smaller Settings section.

Sources has three groups: **Video sources**, **Audio sources**, and **Microphone sources**. Microphone recording can use the system default or a specific connected microphone. Snip saves that choice and reports when a selected device is unavailable.

## Download and install

Download **Snip-v0.1.4-preview-macos-arm64.zip** and its SHA-256 checksum file below. Snip requires an Apple Silicon Mac running macOS 15 or later.

1. Unzip and move **Snip.app** to **Applications**.
2. Open Snip. This preview is ad hoc signed and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after the first attempt. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Grant **Screen & System Audio Recording** when asked. Enable the microphone in **Settings → Sources** to request **Microphone** access. If you change permissions in System Settings, quit and reopen Snip.
4. Click the Snip menu bar icon for compact controls, then choose **Full editor** to select video, app audio, and microphone sources. **⌘⇧9** saves a clip; **⌘⌥P** pauses or resumes capture by default.

Place the checksum file beside the ZIP and run `shasum -a 256 -c Snip-v0.1.4-preview-macos-arm64.zip.sha256` to verify the download.
