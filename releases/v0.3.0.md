## Highlights

- Redesigned the compact controls and full settings with Hush's native translucent material and a clearer tab layout.
- Settings save and apply automatically; the Apply and Done buttons are removed.
- Added optional automatic updates from the Snip GitHub releases.
- Checks release ZIP checksums before installation and asks before updating.
- Shortened the settings copy and removed redundant explanations.

## Compatibility

- Apple Silicon Mac
- macOS 15 or later
- Ad hoc signed; not notarized
- On first run, if macOS blocks Snip, open **System Settings → Privacy & Security → FileVault → Open Anyway**, confirm, and open Snip again.
